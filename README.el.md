## Τι Είναι

Το **SafeSales Order SMS** είναι desktop εφαρμογή που βοηθά ομάδες operations να στέλνουν ενημερωτικά SMS αποστολών γρήγορα και με συνέπεια.

Από ένα καθαρό περιβάλλον μπορείς να εισάγεις courier αρχεία, να ελέγχεις γραμμές, να στέλνεις μεμονωμένα ή μαζικά μηνύματα tracking και να παρακολουθείς την κατάσταση σε πραγματικό χρόνο.

## Highlights

- **Μεμονωμένη αποστολή SMS** με προαιρετικό sender ID.
- **Μαζική αποστολή από Excel** για ACS και Box Express.
- **Templates ανά courier** με αυτόματη εισαγωγή voucher.
- **Ομαδοποίηση επαφών ανά ημέρα και courier** για οργάνωση.
- **Ένδειξη API κατάστασης και υπολοίπου** μέσα στην εφαρμογή.
- **Αποθήκευση ρυθμίσεων** για API key και export directory.

## Τυπική Ροή Χρήσης

1. Προσθέτεις το EasySMS API key από τις Ρυθμίσεις.
2. Επιλέγεις αρχεία ACS και/ή Box Express.
3. Κάνεις process και ελέγχεις τις γραμμές αποστολών.
4. Ορίζεις courier στόχο και sender ID.
5. Στέλνεις μαζικά και παρακολουθείς τα activity logs.

## Σε Ποιους Απευθύνεται

- Ομάδες e-commerce και operations
- Back-office χρήστες με καθημερινή επεξεργασία courier exports
- Επιχειρήσεις που θέλουν ελαφρύ εργαλείο SMS για Windows

## Τεχνολογικό Snapshot

- Python desktop εφαρμογή
- WinUI 3 shell (`win32more`)
- Διασύνδεση με EasySMS API
- Excel parsing pipeline για courier αρχεία
